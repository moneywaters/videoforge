# Neon Database Setup for VideoForge

This document describes how to set up and manage Neon PostgreSQL databases for the VideoForge microservices architecture.

## Overview

VideoForge uses Neon as a serverless PostgreSQL solution for development and production databases. Each of the 11 microservices uses its own dedicated database for data isolation.

### Why Neon?

- **Serverless**: No database servers to manage
- **Autoscaling**: Scales to zero when not in use (free tier)
- **Free Tier**: 512 MB storage, 190 compute hours/month
- **SSL Required**: Built-in encryption
- **Branches**: Easy development branches

## Prerequisites

1. Neon account at https://neon.tech
2. API key (from Console > Settings > API Keys)
3. `curl` and `jq` installed

## Setup Steps

### 1. Run the Setup Script

```bash
# Set your API key
export NEON_API_KEY=napi_xxxxxxxx

# Run the setup script
./scripts/neon-setup.sh
```

The script will:
- Create a project named "videoforge"
- Create databases for all 11 services
- Save connection strings to `.env.neon`

### 2. Update Environment Variables

Add the generated values to your `.env` file:

```bash
# Copy Neon config to your env file
cat .env.neon >> .env

# Or source it directly for development
source .env.neon
```

### 3. Test Connections

```bash
# Test a specific service connection
psql "$(echo $DATABASE_URL_USER)"
```

## Connection String Format

Neon connection strings are PostgreSQL URLs with SSL required:

```
postgres://username:password@host/database?sslmode=require
```

Example:
```
postgres://neondb_owner:password@ep-xyz.us-east-1.aws.neon.tech/videoforge_user?sslmode=require
```

### Connection String Components

- **Protocol**: `postgres://` (PostgreSQL)
- **Username**: `neondb_owner` (Neon default)
- **Password**: Generated by Neon
- **Host**: `ep-xxx.region.aws.neon.tech` (endpoint)
- **Database**: Service-specific database name
- **sslmode**: Required for Neon

## Neon-Specific Configuration

### Connection Pool Settings

Since Neon is serverless, use these optimized settings:

```go
// MaxConns: 10 (Neon free tier limit)
// MinConns: 2 (keep warm connections)
// MaxConnLifetime: 1 hour
// MaxConnIdleTime: 30 minutes
// ConnectTimeout: 10 seconds
```

### Environment Variable Priority

The services check for database URLs in this order:

1. `DATABASE_URL_<SERVICE>` (e.g., `DATABASE_URL_USER`)
2. `DATABASE_URL` (fallback)
3. Local PostgreSQL (default)

## Managing Neon Resources

### View Databases in Console

1. Go to https://console.neon.tech
2. Select your project
3. Click "Tables" to view databases

### Create a Development Branch

```bash
# Create a new branch for development
curl -X POST "https://console.neon.tech/api/v2/projects/{project_id}/branches" \
  -H "Authorization: Bearer $NEON_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"branch": {"name": "development"}}'
```

### Reset Database

```bash
# Drop and recreate database
curl -X DELETE "https://console.neon.tech/api/v2/projects/{project_id}/databases/{database}" \
  -H "Authorization: Bearer $NEON_API_KEY"

# Recreate via the setup script
./scripts/neon-setup.sh
```

## Security Considerations

### API Key Security

- Store API key in environment variable, not in code
- Never commit API keys to version control
- Rotate keys periodically
- Use least-privilege principle

### Connection Security

- Always use `sslmode=require`
- Don't expose connection strings in logs
- Use different credentials per environment

## Troubleshooting

### Connection Timeouts

If you see connection timeouts:
- Check your internet connection
- Verify the endpoint is correct
- Try connecting from a different network

### "Too Many Connections"

Neon free tier allows 10 connections max. If you hit this limit:
- Reduce `MaxConns` in your pool configuration
- Implement connection pooling at the application level
- Upgrade to Neon Pro

### Authentication Failed

- Verify the connection string is correct
- Check if the password was rotated
- Ensure the database exists

### Project Not Found

- Verify `NEON_PROJECT_ID` is set correctly
- Check your API key has the right permissions
